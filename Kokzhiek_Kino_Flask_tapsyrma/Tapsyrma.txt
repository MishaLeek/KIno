ПРАКТИКАЛЫҚ ЖҰМЫС
«КӨКЖИЕК» КИНОТЕАТРЫ САЙТЫНДАҒЫ БИЛЕТ САТЫП АЛУ ҚАТЕЛЕРІН ТАУЫП, ТҮЗЕТУ (DEBUGGING)
==============================================================================

Технологиялар:   Python 3, Flask, SQLite, HTML / CSS / JavaScript
Орындау уақыты:  2 академиялық сағат (80–90 минут)
Жұмыс түрі:      жеке


------------------------------------------------------------------------------
1. ЖАҒДАЯТ
------------------------------------------------------------------------------
Сіз «Көкжиек» кинотеатрының веб-әзірлеушісісіз. Кинотеатр сайтында афиша,
фильмдер беті, зал сызбасы бойынша орын таңдау және электрондық билет бар.
Сайтта тіркелу жоқ: көрермен орынды таңдап, аты-жөнін, телефонын және
email-ын жазады да, бірден билет алады.

Соңғы жаңартудан кейін көрермендер шағымдана бастады:

        «Билет сатып ала алмаймын!»

Сайттың басқа бөліктері (афиша, фильмдер, зал сызбасы, билетті табу беті)
дұрыс жұмыс істейді. Ақау тек БИЛЕТ САТЫП АЛУ процесінде.

Тимлид сізге тапсырма берді: ақаудың себебін тауып, түзету және не
істегеніңізді есеп түрінде жазып беру.


------------------------------------------------------------------------------
2. МАҚСАТ
------------------------------------------------------------------------------
Көрермен орын таңдап, билет сатып алғанда ДӘЛ ӨЗІ ТАҢДАҒАН фильмге, күнге,
уақытқа және залға билет алатындай, ал сатылған орындар залда бос болып
қалмайтындай етіп кодты түзету.

МАҢЫЗДЫ: сатып алу процесінде ҮШ қате бар. Олар тізбек құрайды: біреуін
түзеткенде келесісі көрінеді. Қателер әртүрлі жерде: тек Python файлдарын
емес, HTML шаблондарын да тексеріңіз.


------------------------------------------------------------------------------
3. ЖОБАНЫ ІСКЕ ҚОСУ
------------------------------------------------------------------------------
Қажет: Python 3.9 немесе жаңарақ нұсқасы. Тексеру:  python --version
Flask кітапханасын орнату үшін бір рет интернет қажет.

Windows
  1-тәсіл (оңай): 1_Qatesi_bar папкасындағы iske_qosu.bat файлын екі рет
  басыңыз.

  2-тәсіл (терминал):
      cd 1_Qatesi_bar
      python -m pip install -r requirements.txt
      python app.py

Linux / macOS
      cd 1_Qatesi_bar
      python3 -m venv venv
      source venv/bin/activate
      pip install -r requirements.txt
      python3 app.py

Терминалда «Running on http://127.0.0.1:5000» жазуы шыққанда, браузерде
мына мекенжайды ашыңыз:

      http://127.0.0.1:5000

Серверді тоқтату: терминалда Ctrl + C.

Дерекқор (instance/kokzhiek.sqlite) бірінші іске қосқанда өзі құрылады.
Сеанстар бүгіннен бастап бес күнге жасалады. Дерекқорды бастапқы күйіне
қайтару үшін серверді тоқтатып, мына екі тәсілдің бірін қолданыңыз:
  - instance/kokzhiek.sqlite файлын өшіру (келесі іске қосқанда қайта құрылады);
  - терминалда:  python -m flask --app app init-db

Салыстыруға арналған дайын билет (билет беті дұрыс жұмыс істейтінін көру үшін):
      «Билетті табу» беті → Тапсырыс коды:  DEMO-2026
                            Email:           demo@example.com

  tests/                 автоматты тесттер

5. ТАПСЫРМА ШАРТТАРЫ
------------------------------------------------------------------------------
1) Сайтты іске қосып, билет сатып алуды өзіңіз қайталаңыз және ақауды көріңіз.
2) Әр қатенің себебін табыңыз: қай файлда, қай жолда және неліктен.
3) Қатені МИНИМАЛДЫ өзгеріспен түзетіңіз. Әр қате бір жолдағы бір сөзді
   немесе бір аргументті өзгерту арқылы түзетіледі.
4) Тыйым салынады:
   - файлдарды толық қайта жазу немесе жою;
   - форма тексерулерін (validators.py) алып тастау;
   - тесттерді (tests/ папкасы) өзгерту;
   - дерекқордағы сеанстарды немесе тапсырыстарды қолмен өзгерту.
5) Әр түзетуден кейін нәтижені браузерде тексеріңіз. Сервер debug
   режимінде жұмыс істейді: .py файлын сақтағанда өзі қайта іске қосылады.

8. КЕҢЕСТЕР (ҚИНАЛСАҢЫЗ ҒАНА ОҚЫҢЫЗ)
------------------------------------------------------------------------------
Жалпы тәсілдер
  - Сервер іске қосылған терминалды қараңыз. Әр сұраныс сонда жазылады:

        "POST /showtimes/20/buy HTTP/1.1" 400 -

    POST — әдіс, /showtimes/20/buy — мекенжай (20 — сеанс нөмірі), 400 — жауап коды.
  - Браузерде F12 басып, Network (Желі) қойындысын ашыңыз. Тапсырысты
    жібергенде buy сұранысын таңдап, Payload қойындысынан браузер серверге
    қандай өрістерді қандай атаулармен жібергенін көріңіз.
  - Debug режимінде Python қатесі шықса, браузерде Traceback көрсетіледі. Оны
    төменнен жоғары оқыңыз: соңғы жол — қатенің түрі мен хабары.
  - Күдікті жерге print(...) қосып, айнымалылардың мәні мен типін
    терминалдан қараңыз: print(repr(x), type(x))
  - Жұмыс істейтін және жұмыс істемейтін бөлікті салыстырыңыз. Мысалы, DEMO-2026
    билеті дұрыс көрсетіледі — демек билет бетінің коды дұрыс.
  - Автоматты тесттердің қайсысы құлап жатқанын қараңыз: тесттің аты мен
    хабарламасы нені тексеретінін айтады.

1-қате бойынша
  - Қате бетіндегі KeyError хабарын оқыңыз. Сервер қандай өріс атауын күтеді?
  - Браузер бұл өрісті қандай атаумен жіберді (F12 → Network → Payload)?
  - Қате Python-да көрінді, бірақ оның себебі басқа файлда болуы мүмкін.

2-қате бойынша
  - Traceback-тағы TypeError хабарын оқыңыз: қандай екі тип салыстырылып тұр?
  - HTML формасынан серверге келген деректер қандай типте болады? Тіпті
    type="number" өрісі де.

3-қате бойынша
  - Билетте қандай фильм, күн және уақыт тұр? Өзіңіз таңдаған сеанспен
    салыстырыңыз. Сатып алған орындарыңыз залда бос па, әлде сатылған ба?
  - Тапсырыс дерекқорға қай сеанстың нөмірімен жазылды? Тексеру үшін
    (1_Qatesi_bar папкасында):

        python -c "import sqlite3; print(sqlite3.connect('instance/kokzhiek.sqlite').execute('SELECT code, showtime_id FROM orders ORDER BY id DESC LIMIT 3').fetchall())"

    Шыққан showtime_id-ді браузердегі мекенжайдағы сеанс нөмірімен
    салыстырыңыз (/showtimes/<нөмір>).
  - Сеанс жазбасында қандай id өрістері бар? schema.sql файлын қараңыз.
